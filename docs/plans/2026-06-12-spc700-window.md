# SPC700 debugging UI — APU-RAM memory window + editable SPC register window

**Status:** ✅ implemented + verified (2026-06-12)

## Context

The SPC700 (SNES audio co-CPU) was deferred in the
[SNES stub-lift](2026-06-11-lift-snes-out-of-scope-stubs.md) purely for lack of a **UI
surface** — only protocol enums existed (`SNES_{GET,SET,RESET}_SPC700` in `slaveio.hpp`), no
client functions, no windows. The MAME side is trivial:
`manager.machine.devices[":soundcpu"]` (s_smp) exposes `.state` regs `PC S P A X Y`, a
`program` address space (64 KB, incl. SPC I/O `$F0-$FF` + IPL ROM `$FFC0+`), and the `:aram`
share.

This adds two surfaces (registers **editable**, matching the main Register window):
1. **APU-RAM memory window** — a new `MTYPE_SPC` memory-window type (byte dump, scroll/goto),
   mirroring the read path of the existing PPU-VRAM window (`MTYPE_PPU` / `RP` / `ReadSlavePPU`)
   but rendered as **bytes** (SPC RAM is byte memory, not 16-bit words like PPU VRAM).
2. **SPC700 register window** — a new dedicated window (the main `reg.cpp` is hardcoded to one
   CPU at compile time, so SPC700 needs its own), showing + **editing** `PC A X Y SP PSW`.

## Feature flag — *features, not platforms*

SPC700 code is guarded by a **feature** macro, not the platform. `global.hpp` maps the build
flag to the platform, and the platform block declares which features it has:
```c
#ifdef SYSTEMSNES
#define SNES
#define SPC700          // SNES has an SPC700 audio co-CPU  ← the feature this plan adds
#endif
```
All new SPC700 code is guarded by **`#ifdef SPC700`** (the capability), never `#ifdef SNES`
(the platform). A future platform with a sound co-CPU just adds `#define SPC700` to its block.
`genmon` (Genesis) never declares `SPC700`, so every addition — incl. the whole `spc_reg.cpp`
TU — vanishes there.

**Side effect neutralized:** `which.cpp` had a dead `#ifdef SPC700 #include "dis700.cpp"` for
an SPC700 disassembler that was never written; defining `SPC700` would have activated that
include and broken the build, so it's commented out (SPC RAM is a byte view, not disassembly).

## Bridge additions (`linux/mame_bridge.lua`)

Handles resolved once in `init_machine()`:
```lua
apu_cpu = manager.machine.devices[":soundcpu"]          -- s_smp
apu_ram = apu_cpu and apu_cpu.spaces["program"] or nil  -- 64 KB SPC700 space
```
Three ASCII commands (mirror existing `R`/`G`/`P`):
- **`RA <addr> <len>`** — APU RAM read → hex (mirror `RP`).
- **`GA`** — read SPC regs → `apu_cpu.state[n].value` for fixed order `PC A X Y S P`, space-sep hex.
- **`PA <pc> <a> <x> <y> <sp> <psw>`** — write SPC regs back; reply `ok`.

## Client (`sliomame.cpp` + `slaveio.hpp`, both `#ifdef SPC700`)

- **`ReadSlaveApuRam(addr, data, len)`** — copy of `ReadSlavePPU` with `RP`→`RA` (no cache; live).
- **`GetSpc700Regs(ULONG r[6])`** — send `GA`, parse 6 hex.
- **`PutSpc700Regs(ULONG r[6])`** — send `PA <6 hex>`.

## Part 1 — APU-RAM window (`memory.cpp`, `#ifdef SPC700`)

- `enum { … MTYPE_PPU, MTYPE_SPC, MTYPE_DIFF }` — `MTYPE_SPC` after `MTYPE_PPU`.
- `memoryTypeMenu[]` — `{"SPC RAM    ",MemoryType,0}` after the `"PPU"` entry (menu index == `MTYPE_SPC`).
- **Per-mType tables all extended** (each is indexed by `mType`, so a new enum value needs a slot
  in *every* table or it reads a neighbour / runs off the end):
  - `memorySize[]` += `1` (byte memory).
  - `dWidthTbl[]` += `3` (byte column width); restructured with `#ifdef`s so the SNES `SPC`
    index gets `3` without colliding with the Genesis index meaning.
  - `mTypeText[]` += `"SPC RAM "` — **without this, the status-line render dereferenced the
    array's `0` terminator (`PrintString(NULL)`) → crash** (caught by the smoke guard below).
- Read dispatch: `case MTYPE_SPC: addr &= 0xffff; ReadSlaveApuRam(addr,xferBuffer,bytesNeeded);`
- `MTYPE_SPC` grouped with **`MTYPE_BYTE`** (not `MTYPE_WORD`/`MTYPE_PPU`) in the value-render
  switch, and added to the outer dump-type case groups in **both** `MemoryGetLineAddr` and
  `MemoryRoutine` (the inner read-dispatch is unreachable unless the outer `case` lists `MTYPE_SPC`).
- **Direct accelerator `Ctrl-R` → SPC RAM** (`MEMORY_SPC` cmd + `memoryKeys[]` entry), mirroring
  the existing `Ctrl-B/W/L/D/Y` type hotkeys. Makes the window keyboard-reachable (the Type
  submenu is otherwise the only route) and headless-verifiable. No-op accelerator on `genmon`.

Note: editing a memory cell still routes through `WriteSlaveData` (main bus) — same pre-existing
limitation as the PPU window. SPC RAM is a **read/view** surface; register **editing** is the
SPC register window. (Adding an APU-RAM write command is a future item if needed.)

## Part 2 — SPC register window (`spc_reg.cpp` / `spc_reg.hpp`, body `#ifdef SPC700`)

Mirror of `reg.cpp`, trimmed to 6 registers, editable like the main window:
- `enum { SPCREG_PC, SPCREG_A, SPCREG_X, SPCREG_Y, SPCREG_SP, SPCREG_PSW };` `#define NUMSPCREGS 6`.
  Names `{"PC","A","X","Y","SP","PSW"}`, masks `{0xffff,0xff,0xff,0xff,0xff,0xff}`.
- `SpcRegRoutine` — per-frame `GetSpc700Regs` then print PC/A/X/Y/SP + decoded PSW flags `N V P B H I Z C`.
- `SetSpcReg` → `GetSpc700Regs`/mask/`PutSpc700Regs`; `SpcRegInput` — click a register gadget →
  `GetExpr(SpcRegEditRout,…)` → write back via `PA`.
- `OpenSpcReg()` — singleton `_window(0,7,26,5,"SPC Register",…)`.

## Part 3 — wiring (all `#ifdef SPC700`)

- `global.hpp`: `#define SPC700` inside the SNES platform block.
- `which.cpp`: comment out the dead `#include "dis700.cpp"`.
- `moninc.hpp`: `#include "spc_reg.hpp"`; `manager.cpp`: `#include "spc_reg.hpp"` (it doesn't use `moninc.hpp`).
- `monkeys.hpp`: `#define CMD_OPENSPCREG KEY_ALTN` (Alt-N; Alt-U was taken by `CMD_CUT`).
- `manager.cpp`: `case CMD_OPENSPCREG: OpenSpcReg(); break;`.
- `monmenu.cpp` `windowMenu[]`: `{"SPC Register  Alt-N",…OpenSpcReg,0}` after Register.
- `CMakeLists.txt` `DRMON_CXX_SRC`: add `spc_reg.cpp`.

```

GA: ffd2 0 0 0 ef 0

RA ffc0 10 (IPL ROM): cdefbde800c61dd0fc8faaf48fbbf578
PA round-trip: ok
PA set A=5a: ok
```
