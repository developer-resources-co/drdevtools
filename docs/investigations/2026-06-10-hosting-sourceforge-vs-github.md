# drdevtools hosting: SourceForge vs. GitHub

**Date:** 2026-06-10
**Question:** Is `drdevtools` only on SourceForge, or did it later migrate to GitHub?

## Answer

**SourceForge only — no GitHub migration found.**

`drdevtools` is the **Developer Resources** Sega Genesis / Super Nintendo
development tools and libraries (source-level debugger, assembler, graphics
tools, game libraries, sample games), originally by Kevin Seghetti & friends
(~1992). Its canonical home is SourceForge; no evidence of a move or mirror to
GitHub.

## Evidence

| Check | Result |
|-------|--------|
| SourceForge project | ✅ Exists — [sourceforge.net/projects/drdevtools](https://sourceforge.net/projects/drdevtools/), site `drdevtools.sourceforge.net` |
| SourceForge wiki — migration notice? | ❌ No mention of GitHub, mirror, or relocation ([wiki](https://sourceforge.net/p/drdevtools/wiki/)) |
| `drdevtools` on Kevin Seghetti's GitHub | ❌ Not present — [github.com/KevinSeghetti](https://github.com/KevinSeghetti) (~17 repos: React/TS, Terraform/AWS, PixiJS; none are the DR tools) |
| `github.com/drdevtools` org/user | ❌ HTTP 404 — does not exist |

## Caveat

A search-engine result summary claimed the tools are "available on GitHub
through the drdevtools project." This does **not** hold up: every concrete
GitHub URL checked was either unrelated (`drtools` projects by other authors)
or a 404. Treat that summary as a conflation, not evidence of a migration.
