# test-roms

Homebrew test ROMs for the drmon MAME bridge — **all generated by
[`generate_test_roms.py`](generate_test_roms.py)** and committed (no third-party code, so
they are safe to vendor). Regenerate with `python3 generate_test_roms.py`; output is
byte-reproducible.

| ROM | Driver | Purpose |
|-----|--------|---------|
| `drmon-test.sfc` | `snes` | 32 KB LoROM NOP sled looping at `$8000` — connectivity / register / memory / step / breakpoint tests (`task test-bridge SYS=snes`). |
| `drmon-test-writer.sfc` | `snes` | 32 KB LoROM that loops `STA $8250` (a write into the ROM window) — makes the write-protect / break-on-write watchpoint fire. Used by `../spikes/verify_features.py`. |
| `drmon-test.md` | `genesis` | 4 KB ROM: reset vectors + NOP sled + `BRA.w $200` loop — Genesis connectivity tests (`task test-bridge SYS=gen`). |

To exercise a commercial title instead, drop any `.sfc`/`.smc` (SNES) here and the harness
will pick it up — but **do not commit copyrighted ROMs**; only the homebrew ROMs above belong
in the repo.
