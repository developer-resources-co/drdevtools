15 Dec 92  1337
	WBNIV	Fixed problem with setting Accumulator in SNES version.
		Basically, the command parser would find the first match
		of an input string against the list of commands.  Since
		there were commands that started with "A", it matched with
		the first one.  I changed the code to return a command if
		there is one and only one match.  Not only does this fix
		the problem with the Accumulator, it is also more correct
		and eliminates ambigious commands.  Although this works,
		it still doesn't address the most basic issue: determining
		whether something is an assignment or a command...
